# New TDABM Application Template

Copy this template to `applications/<application_id>/`.

A new application must recover its own contract from authoritative evidence.
Do not infer variable sets, samples, exclusions or radii from previous
applications.

Suggested progression:

1. source recovery / reconstruction;
2. P1.4-A immutable input freeze;
3. P1.4-B topology-only radius diagnostics;
4. explicit user radius approval;
5. P1.4-C canonical topology freeze;
6. post-freeze recolouring;
7. P1.4-D evidence and robustness;
8. application/paper handover.
